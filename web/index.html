Methodology

How this works

What you're seeing

A snapshot of how long it takes to get from any point in Sheffield to every other point by public transport. Click anywhere to set the starting point — colours show travel time to other parts of the city.

Data

  • Bus + tram timetables — Bus Open Data Service (DfT, Open Government Licence)
  • Walking network — OpenStreetMap, South Yorkshire extract via Geofabrik
  • City boundary — ONS Local Authority District (E08000019), Dec 2024 release
  • Transit overlay — 188 routes (4 tram, 184 bus) from GTFS shape geometries

Routing

Travel times are computed by Conveyal R5 via r5py. For every cell in a 3,935-cell H3 res-9 hex grid (~175 m hexes) we compute the time to every other cell — 15.5 million journeys, around 30 minutes of compute on a laptop.

Why "median"

The exact answer depends on the minute you set off — buses don't come continuously. R5 computes the journey for every minute in a 60-minute window starting Tue 19 May 2026 at 08:30, then reports the median. Read it as: "on a typical morning around 08:30, half the time you'd get there in ≤ X min."

Caveats

  • Single timetable snapshot — no real-time, no disruptions, no fares.
  • Walking legs capped at 30 min — purely walking trips beyond that are excluded.
  • Routes leaving the LAD boundary are clipped — neighbouring towns aren't represented.

Source code

The pipeline (Python) and the web app (TypeScript + MapLibre) are open source — see the project README in the repo.
